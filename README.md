# Etiowo Mark Mbi Portfolio

A responsive, static personal portfolio website focused on:

- AI Evaluation
- AI Training & Data Annotation
- Customer Support
- Content Evaluation
- Quality Assurance

## Files

- `index.html` — main website
- `style.css` — design and responsive styling
- `script.js` — mobile menu and scroll animations

## Run locally

Open `index.html` in a browser.

## Deploy

### Vercel
1. Create a GitHub repository.
2. Upload the three website files.
3. Import the repository into Vercel.
4. No build command is required.

### Netlify
Drag the project folder into Netlify Drop, or connect the GitHub repository.

## Customize

Before publishing, add your preferred email, LinkedIn URL, or other professional contact links if you want them displayed.

The "Download CV" button uses the browser print dialog, where you can choose "Save as PDF".
